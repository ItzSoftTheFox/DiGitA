04 / JEŠTĚ PÁR ODPOVĚDÍ

Než začnete.

Je to aplikace, nebo web? +

DiGitA je instalovatelná desktopová aplikace postavená na Reactu a Tauri. Tento web slouží k představení a stažení. Po instalaci se aplikace otevírá ve vlastním okně.

Mění DiGitA můj repozitář? +

Aktuální verze Git repozitář pouze čte. Commitování, push i merge dál provádíte svými obvyklými nástroji. Obsah kódu DiGitA nesynchronizuje.

Potřebuji účet? +

Lokální přehled repozitáře můžete používat bez přihlášení. Účet potřebujete pro týmy, pozvánky a živé místnosti. Registrace se během uzavřeného pilotu zpřístupňuje podle potřeby.

Je už aplikace připravená pro běžný provoz? +

Zatím jde o vývojový pilot. Funkce se mění a mohou se objevit chyby. Server po nečinnosti může potřebovat chvíli na probuzení. Conflict Radar upozorňuje na překryvy souborů, nepředpovídá každý merge konflikt.

Kde můžu nahlásit chybu? +

Otevřete issue na GitHubu a přidejte popis problému, verzi aplikace a systém. Nevkládejte hesla, tokeny ani citlivý obsah repozitáře.
